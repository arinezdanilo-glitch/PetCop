# 🐾 PetCop — Sistema web de gestión clínica, inventario y ventas (SGT-001)

Proyecto de Sistemas · Universidad Privada del Valle · Equipo **Los Capa 8** · Metodología **XP**

Plataforma para la veterinaria PetCop: clínica, inventario automatizado y POS/pagos unificados, con tres roles (Administrador, Recepcionista, Veterinario).
