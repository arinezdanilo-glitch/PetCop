# Guion de exposición (8–10 min) + defensa (3–5 min)
| Min | Tema | Qué mostrar | Responsable sugerido |
|---|---|---|---|
| 0–1 | Proyecto y equipo | Problema, 55 HU, 5 iteraciones | Imanol |
| 1–2.5 | Repositorio y estructura | GitHub: carpetas, README, `.gitignore` | Ludwing |
| 2.5–4 | Ramas, commits y PR | `main/develop/feature`, Conventional Commits, un PR revisado con CI | Danilo |
| 4–5.5 | Issues y tablero | Issues por HU con labels/milestones; tablero Jira (sprints) | Jhoel |
| 5.5–6.5 | Versionado | Tags `v0.N.0`, Releases, CHANGELOG | Imanol |
| 6.5–8 | Documentación + manual | `docs/`, matriz de roles | Oliver |
| 8–10 | Demo breve | Login por rol: admin ve inventario, recepcionista no | Oliver |

**Preguntas probables:** ¿Por qué `develop`? ¿Cómo evitan conflictos? ¿Qué pasa si falla el CI? ¿Cómo enlazan Jira con GitHub? ¿Por qué el recepcionista no ve el inventario? ¿Cómo se versiona un hotfix?
