```
PetCop/
├─ .github/            plantillas de issues, PR y CI
├─ docs/               backlog, roles, flujo git, manual, guion de exposición
├─ jira/               jira-import.csv (importar backlog a Jira)
├─ scripts/            automatización (issues, ramas)
├─ database/           esquema y scripts SQL
├─ src/
│  ├─ PetCop.Api/      lógica de negocio y API
│  └─ PetCop.Web/      interfaz
├─ tests/              pruebas
├─ CHANGELOG.md
└─ README.md
```
